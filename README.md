One picture of food, judged on how delicious it looks. The entry is a
steaming bowl of ramen built on a single dominant ingredient: thick slices
of glossy, caramelized chashu pork, with a jammy soft-boiled egg, springy
noodles, golden broth and fresh scallions in a dark ceramic bowl.

## How it works

`main.ts` (Node 22, stdlib only, no network) copies the pre-rendered
photograph `entry.png` (1024×1024, JPEG data, 241,379 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png` (falling back to `/output/entry.png`).

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
